# 实现说明

三个后端共用 `rosgpt/planner.py`。它为每个后端提供动作格式与提示词，并在执行前校验字段、动作类型、速度、行程和预计用时。移动底座的正方形计划按顺序展开为移动和旋转。保存的计划由同一个校验器处理。

## 执行路径

- **ROS 2 turtlesim** 通过 `/voice_cmd` 接收计划，读取 `/turtle1/pose`，向 `/turtle1/cmd_vel` 发速度，并调用 `/turtle1/set_pen`。控制器按位姿判断动作完成，在繁忙时拒绝新计划。独立的停止消息会中断当前动作并清空队列。
- **MuJoCo 移动底座** 使用 MuJoCo Menagerie 的 Stanford TidyBot 底盘和位置执行器。控制器以实测位姿为起点，根据动作距离、转角和速度插值生成位置参考，到达后保持位置。相机图由场景的俯视相机生成。
- **SO-101** 在固定版本的 LeRobot 桌面环境中运行。回零采用上游定义的关节目标，夹爪动作调整第六个关节目标，两者都输出仿真实测关节位置。

视觉入口支持按单张图像中的条件选择动作。三套演示的范围是受限的仿真控制，物体定位、导航、抓取和实物控制均超出该范围。

闭环评测入口 `rosgpt/mujoco_harness.py` 在每轮采集图像和位姿，从实测位姿为两个标定位置各生成一个动作候选。模型根据图像选择一个候选，经校验后交给同一个控制器。任务成功由仿真位姿和目标位置独立判定。Ollama 和 OpenAI 请求复用同一套动作校验。
